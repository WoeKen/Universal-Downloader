# 🧩 全能下载器 Chrome / Edge 浏览器接管扩展安装说明

### 📌 极速 10 秒安装步骤：
1. 打开 Chrome / Edge / Brave 等任意 Chromium 浏览器；
2. 在地址栏输入 `chrome://extensions`（Edge 浏览器输入 `edge://extensions`）并按回车；
3. 打开页面右上角的 **「开发者模式 (Developer mode)」** 开关；
4. 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」** 按钮；
5. 选择本目录所在的 `extension` 文件夹即可完成安装！

安装完成后，在网页中右键任何下载链接或视频，均可直接「使用全能下载器极速下载」！
